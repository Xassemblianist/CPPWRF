# Changed path -> suite cases, for tools/ci/affected_cases.py (development runs only: every merge to main is proven by
# the full suite, CONTRIBUTING.md "Development runs on the CI").
#
#   PATTERN   SELECTOR [SELECTOR ...]
#
# PATTERN: a path glob relative to the repository root (* within a path component, ** across components); the first
# line whose pattern matches a changed file decides that file. SELECTORs (their union is selected):
#   KEY=V[,V]  KEY!=V[,V]  KEY>=N   cases whose effective configuration (config file, then the case's --set list;
#                                    unset keys are 0) has that value; KEY without a section is phys.KEY
#   cases:REGEX                      cases whose name matches REGEX (re.search)
#   config                           the changed file is a configuration: the cases that run it
#   group                            the changed file is a group of tests/verify/cases: the cases it defines
#   each:KEY                         one short case for each value of KEY other than 0 (the first in suite order)
#   core                             the core sample (@core below)
#   checks                           no case; the run's translator tests and comparators' self-test only
#   docs                             nothing (documentation)
# A selector prefixed with short: keeps only the short versions (simulated time <= 1200 s: the 3-step, 5-step, 10 and
# 20 min cases); without it the 1 h and longer versions are selected too (the slow 24 h / 72 h cases only with --slow;
# an option selector of more than 40 cases, as WSM6 or YSU, keeps 6 of its long cases unless --all-long).
# A file whose changed lines (git diff) are all comments or blank (# lines in Python, shell, CMake, .ini and .txt
# files; // lines in C++ and CUDA) counts as documentation. A changed file under src/phys/<scheme>/ also selects the
# cases of every scheme directory whose files include it (directly or through other scheme files; #include lines).
# tests/tools/test_affected_cases.py checks that every src/phys/* directory has its own line, that every option
# selector of a scheme selects at least one case and that @core names existing cases.
